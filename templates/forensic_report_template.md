## Workspace 실행 출처

모든 포렌식 보고서·증거설명서·검증 출력·사건 기록에 `python scripts/workspace_provenance.py`의 실제 출력인 `workspace_version`, `git_commit`, `git_dirty`를 기록한다. 생성 시점 값을 보존하고 검증 시점 값은 별도로 기록한다. Git 정보가 없는 배포본은 `unknown`을 그대로 기록하며 추정하지 않는다.
